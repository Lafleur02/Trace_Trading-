# Trace

Trace is a website for a logistics agency specializing in import and export, supporting companies and students in their economic projects.

## About

Trace is a web project developed during my internship at **IAC (Intelligence Artificielle Cameroun)**. The agency it presents helps businesses and students carry out their economic projects, from import and export operations to the logistics that go with them.

The goal of this site is to give the agency a clear online presence, so that clients can discover its services and get in touch easily.
